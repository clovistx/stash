agent harness · Terminal-Bench 4.0 · @RayaneRachid_

Unharnessed troca a lista de tools por um único Python REPL e passa o Claude Code no Terminal-Bench 4.0

Rayane Rachid lançou um agent harness com uma tool só: uma sessão de Python que fica aberta durante a tarefa inteira, enquanto o modelo escreve todo o resto. No gráfico divulgado pelo projeto, o Claude Opus 5.5 no modo max chega a 71,2% no Terminal-Bench 4.0 dentro do Unharnessed, contra cerca de 65% do mesmo modelo no Claude Code, e ainda gasta menos, US$ 12,19 por tarefa.

Post de 15 de novembro · @RayaneRachid_, citado por @AZERDSQ0329 · mais de 110 mil impressões e 1.700 bookmarks

A tese do projeto é que toda tool hardcoded é uma decisão tomada antes, em nome do modelo: o que um read devolve, como um edit é formatado, quanto output sobrevive. Isso fazia sentido quando os modelos precisavam de trilhos, mas cada geração precisa de menos. No Unharnessed, uma única chamada vira um script que lê o arquivo, busca no repositório, muda quarenta lugares e confere o resultado, em um round trip em vez de quatro.

O ganho mais interessante está no contexto. A sessão funciona como um kernel do Jupyter, que continua vivo entre as chamadas: um log de 40 mil linhas fica guardado numa variável, e o modelo puxa só as dez linhas de que precisa. Ele também escreve as próprias funções e as guarda na sessão, e quando o contexto é compactado, os dados, o servidor rodando e essas funções continuam lá. É diferente do code mode de outros harnesses, em que o script só chama as mesmas tools fixas de sempre.

O projeto é escrito em Rust, open source e gratuito, e entra com a assinatura que você já paga, como Claude Pro ou Max, ChatGPT Plus ou Pro, GitHub Copilot, Google AI Pro e Grok, sem precisar de API key. Também aceita chaves de mais de vinte provedores e modelos locais via Ollama, LM Studio, llama.cpp e vLLM. O placar é do próprio projeto, então vale testar numa tarefa sua antes de trocar de ferramenta.

Claude · edição de vídeo · @matheusgobbidev

Matheus Gobbi diz que o Claude editou em 20 minutos este vídeo de pouco mais de um minuto

O post é uma provocação a quem diz que o Claude edita mal. O vídeo vertical tem legendas que pulam palavra por palavra no ritmo da fala, zooms suaves entre as etapas, linhas animadas ligando um passo ao outro e o Matheus num picture-in-picture no canto, com acabamento de quem passou a tarde no editor.

O post passou de 130 mil impressões e 2.500 bookmarks, e as respostas viraram debate. Como ele não detalhou no fio como montou a edição com o Claude, o melhor é ler o vídeo como uma amostra do acabamento possível, e não como receita.

app com IA · Expo · React Native

Por dentro, o vídeo ensina a tirar um app do zero com um app.md, o ChatGPT e o Claude

O roteiro tem seis passos. O Matheus junta referências no Pinterest e na App Store, pede ao ChatGPT um arquivo app.md com o que o app faz, as telas, as features e o estilo visual, e depois manda o Claude ler o arquivo e criar o app com Expo e React Native. O resultado é o Pumpy, um app fitness com um mascote de IA que monta treino e dieta, rodando no celular pelo Expo Go.

Nas respostas, ele lembrou que é um tutorial para quem está começando e que temas como CI/CD ficam para depois. O próximo episódio da série promete login e banco de dados.

Hora do Hands-on

três testes de dez minutos · pra terça
teste 1 · Unharnessed

Rode o Unharnessed com a assinatura que você já paga

Siga a instalação do unharnessed.dev, entre pelo navegador com o plano do Claude, do ChatGPT ou do Grok e dê a ele uma tarefa real do seu repositório, como encontrar testes flaky. Compare quantos turnos ele gasta com o que o seu agente de sempre gastaria na mesma tarefa.

teste 2 · app.md

Escreva um app.md antes do primeiro prompt de código

Separe cinco screenshots de apps que você admira e peça a um modelo um app.md com o que o app faz, as telas, as features e o estilo visual, como no vídeo do Matheus. Depois entregue o arquivo ao seu agente de código com Expo e veja se a primeira tela aparece no Expo Go em menos de dez minutos.

teste 3 · contexto

Teste a ideia do Python REPL no agente que você já usa

Peça ao seu agente que carregue um log longo numa variável de Python e responda só com as dez linhas que explicam o erro, em vez de ler o arquivo inteiro. Compare o consumo de contexto com o jeito de sempre e você vai entender, na prática, a aposta do Unharnessed.
